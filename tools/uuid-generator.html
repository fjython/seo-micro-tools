FAQ

What UUID version is generated?

UUID version 4 (random), using the Web Crypto API when available.

Are UUIDs unique?

UUID v4 has an extremely low collision probability for practical use. They are suitable for IDs, keys, and tokens.

Is generation done on a server?

No. UUIDs are generated locally in your browser.
