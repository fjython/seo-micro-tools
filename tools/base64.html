FAQ

What is Base64 encoding?

Base64 encodes binary or text data into an ASCII string using 64 characters. It is commonly used in data URLs, email, and APIs.

Is encoding done on a server?

No. Encoding and decoding run locally with JavaScript in your browser.

Does it support Unicode?

Yes. Text is handled as UTF-8 before Base64 encoding and after decoding.
